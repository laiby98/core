# Laiba's Energy artifact

This is a self-contained static website. No build step or external assets are required.

To preview it locally from the repository root:

```bash
python3 -m http.server 8000 --directory artifacts/laiba-energy-artifact
```

Then open <http://localhost:8000>.

The folder can be uploaded directly to GitHub Pages, Netlify, Cloudflare Pages, or any basic web host. `index.html` is the entry point.
